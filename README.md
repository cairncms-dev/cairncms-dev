## 🪨 About

Hi! I'm the maintainer for CairnCMS. I created this account to keep CairnCMS work separate from my personal account and day job.

CairnCMS was born out of necessity, as my work relies on the success of the project. I've been involved in open source for as long as I can remember. The first project I contributed to was the Project64 emulator when I was a teenager. This was before GitHub... when codebases were hosted on Sourceforge and patches were submitted on forums. It was the wild west, and I may have downloaded a lot of malware onto my family's computer. Luckily, experiences like that shaped the software engineer that I became.

My background is in highly regulated enterprise environments, using mostly Rust and C, so security and efficiency are naturally just how I think about software. I'd like to think this is evident with the first changes I made to CairnCMS post-fork: stripping the telemetry and cleaning up hundreds of Dependabot alerts (oof).

I am eager to build the CairnCMS community and I'm always happy to chat. Please feel free to reach out at hello@cairncms.dev.
